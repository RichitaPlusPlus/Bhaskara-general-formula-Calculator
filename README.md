# Bhaskara-general-formula-Calculator
A calculator for quadratic or second-degree equations (x^2) made with HTML, CSS, and JavaScript  useful for obtaining results for x1 and x2 in a simple way  it also gives you the value of the discriminant (the value that goes in the root) so you can do it step by step  -with error correction in case infinite numbers appear or the value of “a” is 0
